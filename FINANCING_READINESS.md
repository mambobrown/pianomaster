# Financing Readiness — PianoMaster

**Status:** VALIDATION REQUIRED — music EdTech product.

## Financing thesis
PianoMaster should first validate willingness to pay as a guided learning service/cohort before financing a full app. This reduces software risk and provides real curriculum/retention data.

## Preferred funding paths
- StartGeld for validated education operations.
- Innovation/digitalisation financing for a separately defined qualifying software project after validation.

## Mandatory gates
- Defined learner segment and learning outcome.
- Paid guided pilot/cohort.
- Completion/retention evidence.
- Price and teacher/support economics.
- Original/licensed content rights.
- MVP specification based on observed user behaviour.

## Rejection risks
- Crowded music-learning app market.
- Building software before proving pedagogy/payment.
- High content-production cost.

## Required improvement
Use `paid service first → curriculum evidence → MVP → retention → software financing`.
